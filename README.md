# prueba_tecnica
Prueba técnica para Cinteli, donde se desarrollara 3 vistas principales segun la app de MeetUp. Las cuales seran el home y ver detalles de un evento (Esto para usuarios no logeados), y la tercera vista que sera cuando un usuario se loguea le enseña su home y le permite ver el detalle de un evento (Estas dos vistas estaran protegidas).
Para loguearse se tienen las siguientes credenciales.
email: prueba@yopmail.com
password: prueba123*#
Si se ingresan credenciales diferentes sale una alerta.
A tener en cuenta, como solo se desarrollaron estas 3 vistas pricipales y son datos quemados, muchas de las vistas no tienen todas las interacciones, y en el caso del detalle solo se muestra una misma vista con la misma información.

# Version nodeJs
v20.19.0

# Version Angular CLI
v19.2.19.

# Instalación
- clonar proyecto del repositorio.
- Validar que se tiene instalada y en uso la version correcta del nodejs que es v20.19.0 antes de usar el siguiente comando.
- usar comando "npm i" o "npm install"
- una vez instalada las dependencias puedes ejecutar el proyecto con el comando "npm run start"
