# prueba_tecnica
Prueba técnica para Cinteli, donde se desarrollara 3 vistas principales segun la app de MeetUp....

# Version nodeJs
v20.19.0

# Version Angular CLI
v19.2.19.

# Instalación
- clonar proyecto del repositorio.
- Validar que se tiene instalada y en uso la version correcta del nodejs que es v20.19.0 antes de usar el siguiente comando.
- usar comando "npm i" o "npm install"
- una vez instalada las dependencias puedes ejecutar el proyecto con el comando "npm run start"
